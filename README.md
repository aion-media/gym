# 🏋️ Gym Coach — Веб-дневник тренировок с интеграцией в Google Таблицу

Легковесное, быстрое мобильное веб-приложение для клиентов тренера с прямой двусторонней синхронизацией с Google Таблицей (вкладка **«New Gym»**).

---

## 🚀 Основные возможности

1. **Два тренировочных блока:** быстрое переключение между **«Блок 1»** и **«Блок 2»**.
2. **Складные аккордеоны:** удобный обзор всех упражнений без перегрузки экрана.
3. **Умный план и авто-прогрессия нагрузки:**
   - Если тренер расписал новый столбец в таблице — приложение показывает именно план тренера.
   - **Если тренер ещё не успел внести новый план** — приложение автоматически берёт результаты прошлой тренировки и **добавляет +2 повторения в двух последних подходах каждого упражнения** (например: `15х12`, `15х12`, `15х12` → `15х12`, `15х14`, `15х14`).
4. **Быстрый ввод и галочки:**
   - Прошлый результат показан слева для ориентира.
   - Текущий подход уже предзаполнен: клиент может в 1 клик подтвердить его галочкой `✔` или быстро отредактировать вес/повторы прямо в поле.
5. **Встроенный таймер отдыха:** отсчёт 60с / 90с / 120с с виброоткликом и звуковым сигналом между подходами.
6. **Завершение и отправка:** одной кнопкой все выполненные подходы заносятся в Google Таблицу тренера с сегодняшней датой.

---

## 📁 Структура файлов проекта

* **`index.html`** — Мобильное веб-приложение (HTML5 / CSS3 / JavaScript). Не требует сторонних серверов, работает прямо из браузера или через GitHub Pages.
* **`Code.gs`** — Код для редактора **Google Apps Script**, который связывает веб-приложение с вашей Google Таблицей.
* **`README.md`** — Данная инструкция.

## ⚙️ Пошаговая настройка за 2 минуты

### Шаг 1. Вставка скрипта в вашу Google Таблицу

1. Откройте вашу Google Таблицу:  
   👉 [Таблица тренера (New Gym)](https://docs.google.com/spreadsheets/d/1GJM3RAG9bbNJgjLn6jtJC7mOpkYE5zkqIVPh3H8a5jo/edit?gid=1149356393#gid=1149356393)
2. В верхнем меню таблицы нажмите:  
   **«Расширения» (Extensions)** → **«Apps Script»**.
3. В открывшемся редакторе удалите весь стандартный текст (`function myFunction() {...}`).
4. Откройте файл [`Code.gs`](file:///c:/%D0%A2%D1%80%D0%B5%D0%BD%D0%B5%D1%80/Code.gs), скопируйте весь его код и вставьте в редактор Apps Script.
5. Нажмите на иконку дискеты **«Сохранить проект»** (Ctrl + S).

---

### Шаг 2. Публикация веб-приложения (Развертывание)

1. В правом верхнем углу Apps Script нажмите синюю кнопку **«Начать развертывание» (Deploy)** → **«Новое развертывание» (New deployment)**.
2. Нажмите на шестеренку слева от «Выберите тип» и выберите **«Веб-приложение» (Web app)**.
3. Заполните поля:
   - **Описание:** `Gym API`
   - **Запуск от имени:** `От моего имени (ваш_email)`
   - **У кого есть доступ:** **`Все` (Anyone)** *(это обязательно, чтобы телефон клиента мог отправлять данные в таблицу)*.
4. Нажмите кнопку **«Развернуть» (Deploy)**.
5. Google попросит предоставить доступ к вашей таблице:
   - Нажмите *«Предоставить доступ»* → выберите ваш Google-аккаунт.
   - Если появится окно «Google не проверял это приложение»: нажмите ссылку *«Дополнительно» (Advanced)* внизу → *«Перейти на страницу (небезопасно)»* → *«Разрешить»*.
6. **Скопируйте ссылку из поля «Веб-приложение (URL)»** (она заканчивается на `/exec`).

---

### Шаг 3. Подключение ссылки в приложении

1. Откройте файл `index.html` в любом браузере (на компьютере или телефоне).
2. В правом верхнем углу нажмите кнопку шестеренки ⚙️.
3. Вставьте скопированную ссылку в поле и нажмите **«Сохранить»**.
4. Всё! Теперь приложение подключено к вашей Google Таблице в режиме реального времени.

## 🌐 Как бесплатно опубликовать на GitHub Pages (для клиента)

Чтобы у вашего клиента была простая короткая ссылка (например, `https://ваш-логин.github.io/gym/`), которую можно открыть на любом смартфоне:

1. Создайте новый публичный репозиторий на [GitHub.com](https://github.com) (например, `gym-tracker`).
2. Загрузите файлы `index.html` и `README.md` в этот репозиторий:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/gym-tracker.git
   git push -u origin main
   ```
3. В настройках репозитория на GitHub перейдите в раздел:  
   **Settings** → **Pages** → в блоке **Branch** выберите `main` и папку `/(root)` → нажмите **Save**.
4. Через 30 секунд появится готовая ссылка на сайт!
5. Отправьте эту ссылку клиенту. На смартфоне он может нажать в браузере: *«Поделиться» → «На экран Домой»*, и приложение появится как иконка отдельного мобильного приложения.

## 📋 Как тренеру вести таблицу

* **Если хотите сами расписать план:**  
  Вставьте новый столбец справа в нужный блок, напишите дату в шапке и укажите веса/повторения. Приложение сразу покажет этот план клиенту.
* **Если вы не успели расписать план:**  
  Ничего страшного! Приложение автоматически возьмёт прошлые результаты и прибавит **+2 повторения в двух последних подходах каждого упражнения**.
* **После завершения тренировки клиентом:**  
  Все фактические веса и повторы аккуратно записываются в таблицу с сегодняшней датой и пометкой `[Готово]`.
